# ВЕКТОР — персональный навигатор развития

## 📋 Описание проекта

**ВЕКТОР** — ИИ-приложение в MAX, которое помогает пользователю превратить интерес или цель в понятный путь к результату. Приложение помогает определить необходимые навыки, построить персональную траекторию развития и подобрать практические задания.

## 🛠 Технологии

- **Python**
- **FastAPI**
- **PostgreSQL**
- **Ollama** и **gpt-oss:120b**
- **HTML, CSS, JavaScript**
- **Docker**
- **MAX Bot API**

## 📦 Требования для запуска

Перед запуском необходимо установить:

- [Docker](https://www.docker.com/get-started)
- [Git](https://git-scm.com/downloads) (для получения проекта из репозитория)

## 📁 Структура проекта

В корневой директории проекта должны находиться:

- `Dockerfile` — инструкции для сборки Docker-образа
- `requirements.txt` — список используемых Python-библиотек и их версий
- `README.md` — инструкция по сборке и запуску проекта
- исходный код приложения и необходимые файлы конфигурации

## 🚀 Сборка Docker-образа

1. Откройте терминал.
2. Перейдите в корневую директорию проекта.
3. Выполните команду:

```bash
docker build -t vector .
```

После выполнения команды Docker соберёт образ проекта с именем `vector`.

## 💾 Подготовка хранилища данных

Для сохранения данных PostgreSQL необходимо создать Docker Volume:

```bash
docker volume create postgres_data
```

Volume позволяет сохранять данные базы данных при остановке и повторном запуске контейнера.

## ▶️ Запуск проекта

Для запуска приложения выполните команду:

```bash
docker run -d \
  --name vector \
  -p 5050:5000 \
  -v postgres_data:/var/lib/postgresql/data \
  vector
```

После запуска контейнер будет работать в фоновом режиме.

### Параметры команды

| Параметр | Описание |
|----------|----------|
| `-d` | Запуск контейнера в фоновом режиме |
| `--name vector` | Имя контейнера |
| `-p 5050:5000` | Проброс порта приложения |
| `-v postgres_data:/var/lib/postgresql/data` | Подключение постоянного хранилища PostgreSQL |
| `vector` | Имя Docker-образа |

## ✅ Проверка работы приложения

Проверить, запущен ли контейнер:

```bash
docker ps
```

Просмотр логов приложения:

```bash
docker logs vector
```

Просмотр логов в реальном времени:

```bash
docker logs -f vector
```

После успешного запуска приложение должно быть доступно через настроенный сервер и соответствующий адрес.

## ⏹ Остановка проекта

Остановить контейнер:

```bash
docker stop vector
```

Повторный запуск:

```bash
docker start vector
```

Удаление контейнера:

```bash
docker rm -f vector
```

> ⚠️ Удаление контейнера не удаляет созданный Docker Volume с данными PostgreSQL.

## 🔄 Обновление проекта

Если исходный код проекта изменился, необходимо заново собрать Docker-образ:

```bash
docker build -t vector .
```

Перед повторным запуском старый контейнер можно остановить и удалить:

```bash
docker stop vector
docker rm vector
```

Затем запустите новый контейнер командой из раздела [«Запуск проекта»](#️-запуск-проекта).
